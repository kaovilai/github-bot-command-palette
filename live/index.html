GitHub Bot Command Palette — live logic

This site hosts the opt-in, data-only logic.json consumed by the GitHub Bot Command Palette browser extension. Source and deployment live in kaovilai/github-bot-command-palette (live/ + .github/workflows/deploy-live-logic.yml).

The document can override only whitelisted data: the checks-section and legacy check-row selectors, failure-log grep patterns, and the error-line cap. It never contains or executes code — changing those values takes effect on the extension's next poll (≤60s) without reloading the extension or the page, when the opt-in "Live updates" setting is enabled.
